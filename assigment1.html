Welcome!In this guide, I will introduce you to 80 powerful HTML tags, breaking down exactly what they do and showing you how to code them step-by-step, and just to remind you, HTML is not a programming language but a markup language.

If a website were a house, what role do HTML tags play?
HTML tags are the foundational building blocks of a webpage, acting as hidden keywords wrapped in angle brackets (< >) that tell your web browser exactly how to structure and display content like text, images, and links. For more information click here or watch tutorials.

The Core Families of HTML Tags

In this section, I will break down the different types of HTML tags and explore how they function together. Listed below are the different types of tags.

  • Document structure Tags:
    These tags build the skeleton of every web page. Think of them as the foundation and frame of a house. On a new page on your visual code, press Shift1, it will give you the Document structure tags. They are majorly used for initialization.
  • List Tags
    Lists group related items. Browsers add bullets, numbers and indentation automatically. Examples of list tags are, an unordered list, shown with bullets. Use it when the order does not matter, an ordered list, shown with numbers. Use it when order matters (steps, rankings), a description list, a set of terms with their meanings, e.t.c.
  • Text formatting and semantic Tags
    These change how a piece of text looks and tell the browser what it means. Many look the same on screen. For example strong and b (for bold) are both bold, but they mean different things to screen readers and search engines.
  • Form Tags
    Forms collect information from visitors (login, sign-up, search, contact). The browser sends the data to a server when the form is submitted. Examples are, form, label, input, select and so on. Note! all the examples are paired tags.
  • Table Tags
    Tables show data in rows and columns (schedules, price lists, results). Do not use tables for page layout. Examples are, table, caption, thread, and so on. Note! all the examples are paired tags.
  • Links and media tags
    These tags connect pages together and bring in pictures, sound, video and graphics. Examples are, a, img, picture, figure, source and so on. Note! all the examples are paired tags.
